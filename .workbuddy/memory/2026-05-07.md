# 2026-05-07

## 修复 server_downloader.js URL 获取失败问题

**问题**：点击 "Download to Server" 按钮时，`inferUrlAsync` 无法从 DOM 自动推断模型下载 URL（ComfyUI 缺失模型对话框里 URL 存储在 JS 内部状态，不暴露到 DOM），导致直接显示 "No URL" 报错。

**修复内容（`web/js/server_downloader.js`）**：
1. 自动推断 URL 失败时，弹出自定义模态输入框，让用户手动粘贴 URL（同时自动尝试读取剪贴板预填充）。
2. 文件名不含合法模型扩展名时，弹出文件名确认框让用户修改/确认。
3. `sanitizeFilename` 正则从严格白名单改为黑名单（过滤 `/\\:*?"<>|`），支持中文等更多合法字符。
4. `extractFilenameFromUrl` 新增从 query 参数（`filename`/`name`）提取文件名（兼容 HuggingFace 等接口）。
5. 新增 `hasModelExtension` 辅助函数判断是否有合法扩展名。
6. 按钮文字改为中文，增加成功/失败的颜色反馈样式。
